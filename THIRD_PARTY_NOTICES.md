# Third-party materials and publication review

This document identifies material with rights or conditions separate from the project's original code. It is not a legal determination or a blanket redistribution license.

## Original project code

No repository-wide software license has been selected. Public GitHub visibility alone does not make the original code permissively licensed. The repository owner should choose a license before inviting reuse under open-source terms. Any future code license must explicitly distinguish third-party instruments, papers, images and model artifacts.

## Questionnaires

- **SD-3:** attributed to Jones and Paulhus; transcribed from the appendices of Li et al., arXiv:2212.10529v1. Review the original instrument's permissions before public redistribution or commercial use.
- **BFI:** attributed to John and Srivastava; transcribed from the same paper's appendices. Review the original instrument's permissions before public redistribution or commercial use.
- **Satisfaction With Life Scale and Flourishing Scale:** copyrighted instruments attributed to Diener and colleagues. The project records non-commercial use with attribution according to the [official scale site](https://eddiener.com/scales/). Permission for use is not automatically permission for every form of redistribution; review the current terms for the intended publication.
- **IPIP:** item sets are described as public domain by the [IPIP permissions page](https://ipip.ori.org/newPermission.htm). Scoring sources and limitations are retained in each questionnaire definition. The NEO-like IPIP facets are not the proprietary NEO-PI-R instrument.

Read each JSON definition's `source`, `source_url`, `license` and `permission_url` where supplied. Publishing questionnaire text in JSON and in the website's item disclosures both require rights review. This repository's ignore rules do not exclude those definitions or establish that redistribution is permitted.

## Visual stimuli

- The nine organic illustrations are generated by the project and have versioned seeds and hashes. They are not historical Rorschach plates or validated psychological tests. Their distribution terms must be covered by the owner's eventual license decision.
- Historical Rorschach JPEG reproductions are attributed to Hermann Rorschach (1921). Wikimedia Commons labeled the archived versions public domain. Original file versions, source-page revisions and retrieved licensing metadata are recorded in `assets/rorschach/manifest.json`; preserve this provenance and review jurisdiction-specific requirements.
- Viewing the historical plates may affect subsequent human assessments. Their availability does not validate clinical use, and model outputs may reflect training-data familiarity.

## Papers and model artifacts

Local PDFs in `papers/` are excluded from Git by default; cite or link to the originals instead. See [papers/README.md](papers/README.md).

Ollama model weights are downloaded separately and are not covered by a repository license. Review each model's own terms. Model metadata and licenses may also be embedded in saved run manifests, which are excluded from Git by default.

## Dependencies and research exports

Ruby gems and developer tools retain their respective licenses. Dependency installation directories are ignored; the Gemfile and lockfile remain source-controlled inputs.

Generated research exports are not a sanitized public dataset. They may contain copyrighted prompt text, raw model outputs, local paths, hardware metadata or offensive content. Publishing them requires a separate review and an explicit dataset licensing decision; do not assume a future code license covers them.
